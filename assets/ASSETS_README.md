## 🖼️ Screenshots Guide

### How to Create Theme Screenshots:

1. **Open VS Code with a theme**
2. **Open a code file** (recommended languages):
   - JavaScript/React (most popular)
   - Python
   - TypeScript/TSX
   - Rust
   - Solidity (for Web3 themes)

3. **Use realistic code** (not "hello world"):
   - Example: A React component with hooks
   - Example: Python ML model training
   - Example: Rust async function

4. **Window size**: 1920x1080 or 1280x720

5. **Take screenshot**:
   - Windows: `Win + Shift + S`
   - Mac: `Cmd + Shift + 4`
   - Linux: `Shift + PrtScn`

6. **Save as**: `themename-screenshot.png`
   - Example: `neon-hustle-dark-screenshot.png`

7. **Compress** (use tinypng.com or similar)
   - Goal: < 500KB per image

### Recommended Settings for Screenshots:
```json
{
  "editor.fontSize": 16,
  "editor.fontFamily": "'Fira Code', 'Cascadia Code', monospace",
  "editor.fontLigatures": true,
  "editor.lineNumbers": "on",
  "editor.minimap.enabled": true,
  "workbench.colorTheme": "Your Theme Name Here"
}
```

## 🎨 Icon Guide

### Extension Icon Requirements:
- **Size**: 512x512 pixels
- **Format**: PNG (with transparency)
- **Style**: Simple, recognizable, professional
- **Colors**: Match your brand

### Tools to Create Icon:
- **Figma** (free, recommended)
- **Canva** (easy templates)
- **AI generators**: DALL-E, Midjourney
- **Design yourself** in Photoshop/GIMP

### Icon Ideas:
- Diamond shape (💎)
- Code brackets with gradient
- Minimal "E" letter with neon glow
- Abstract geometric shape

### Placeholder Icon:
Until you have a custom icon, use a simple colored square:
1. Create 512x512 PNG
2. Solid color background (your brand color)
3. White "ET" text in center (Elite Themes)

**Save as:** `assets/icons/logo.png`

## 💡 Pro Tips

### Tip 1: Consistent Branding
- Use same color palette across all assets
- Example: Elite purple (#a78bfa) + neon green (#00ff88)

### Tip 2: Show Real Code
- Don't use generic "hello world"
- Use actual React/Python/Rust code with imports
- Syntax highlighting must be visible

### Tip 3: Dark Backgrounds for Screenshots
- Most devs use dark themes
- Your themes will stand out more on dark background

### Tip 4: Add Captions
- Label each screenshot: "NeonHustle Dark — React Component"
- Helps users understand what they're looking at
