# Assets Directory

## Required Files

To publish to VS Code Marketplace, you need:

### 1. Logo (Required)
- **File:** `logo.png`
- **Size:** 512x512 pixels minimum (1024x1024 recommended)
- **Format:** PNG with transparency
- **Style:** Modern, minimalist, recognizable at small sizes

**How to create:**
1. Use AI generators (DALL-E, Midjourney): "minimalist geometric logo for elite developer tools, neon colors, dark background"
2. Use Canva (free): Search "tech logo templates"
3. Use Figma: Design simple geometric shapes with gradient
4. Hire on Fiverr: $10-50 for professional logo

**Quick AI Prompt:**
```
"Create a minimalist logo for Elite Themes, a premium VS Code theme collection. 
Style: Geometric, modern, neon accents (magenta, cyan, gold). 
Dark background. Simple enough to recognize at 32x32px. 
Think: luxury tech, elite developers, 2026 aesthetic."
```

### 2. Screenshots (Recommended)
Create 5-10 screenshots showing:
- Different themes in action
- Real code (React, Python, TypeScript)
- Before/After comparisons
- Feature highlights (terminal colors, semantic highlighting)

**Naming:**
- `screenshot-neonhustle.png`
- `screenshot-millioncode.png`
- `screenshot-cryptodusk.png`
- etc.

### 3. Marketing Assets (Optional but powerful)
- `banner.png` (1200x400) - For GitHub/Twitter
- `mockup-*.png` - IDE mockups for social media
- `comparison.png` - Elite Themes vs competition

2. Prompt: "minimalist tech logo, neon geometric shapes, dark background"
3. Download 1024x1024 PNG
4. Save as `logo.png` in this folder
5. Done!
