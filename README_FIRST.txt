1. Замени YOUR_USERNAME на свой GitHub username
   (поиск по всем файлам)

2. Создай logo.png (512x512) в assets/icons/
   (используй AI генератор или Canva)

3. Опубликуй:
   npm install
   npx vsce login YOUR_PUBLISHER
   npx vsce publish

4. Запусти:
   - Твит с #EliteThemes
   - Пост на Reddit r/vscode
   - Пост на ProductHunt
