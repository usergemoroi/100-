## 🚀 Быстрый старт

### Установка (3 способа):

**Способ 1: Через Marketplace (проще всего)**
1. Открыть VS Code
2. Нажать `Ctrl+Shift+X` (расширения)
3. Искать "Elite Themes 2026"
4. Нажать "Install"

**Способ 2: Быстрая команда**
1. Нажать `Ctrl+P`
2. Вставить: `ext install elite-dev-studio.elite-themes-2026`
3. Enter

**Способ 3: Вручную**
```bash
git clone https://github.com/YOUR_USERNAME/elite-themes-2026.git
code elite-themes-2026
# Нажать F5 для тестирования
```

### Активация темы:
1. Нажать `Ctrl+K`, затем `Ctrl+T`
2. Выбрать любую из 100 тем
3. Готово!

**Полная инструкция для новичков:** [BEGINNER_GUIDE.md](./BEGINNER_GUIDE.md)
