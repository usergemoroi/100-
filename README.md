## 🔥 Quick Start (Free Version)

### Option 1: VS Code Marketplace (Easiest)
1. Open VS Code
2. Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac)
3. Type: `ext install elite-dev-studio.elite-themes-2026`
4. Press Enter
5. Choose your theme: `Ctrl+K Ctrl+T` → select any Elite Theme

### Option 2: Manual Install (GitHub)
```bash
# Clone this repo
git clone https://github.com/YOUR_USERNAME/elite-themes-2026.git

# Open in VS Code
code elite-themes-2026

# Press F5 to test themes locally
```

### No Skills Needed — Complete Beginner Guide

**Never used VS Code extensions? No problem:**

1. **Download VS Code** (if you don't have it)
   - Go to https://code.visualstudio.com
   - Click "Download" → Install like any app

2. **Open VS Code**

3. **Install Elite Themes:**
   - Click the 4-square icon on the left sidebar (Extensions)
   - OR press `Ctrl+Shift+X` (Windows) / `Cmd+Shift+X` (Mac)
   - Type "Elite Themes 2026" in search box
   - Click "Install" on our extension

4. **Activate a theme:**
   - Press `Ctrl+K` then `Ctrl+T` (release keys, then press them)
   - Scroll through 100 themes
   - Click one you like
   - Done! Your code now looks 10x better

5. **Change themes anytime:**
   - Same shortcut: `Ctrl+K Ctrl+T`
   - Try different themes for different moods
