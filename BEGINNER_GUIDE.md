## 📦 Step 1: Install VS Code (if you don't have it)

### Windows:
1. Go to https://code.visualstudio.com
2. Click the big blue **"Download for Windows"** button
3. Open the downloaded file (`VSCodeSetup.exe`)
4. Click "Next" → "Next" → "Install"
5. Click "Finish"
6. VS Code will open automatically

### Mac:
1. Go to https://code.visualstudio.com
2. Click **"Download for macOS"**
3. Open the downloaded `.zip` file
4. Drag "Visual Studio Code" to your Applications folder
5. Open VS Code from Applications

### Linux:
1. Go to https://code.visualstudio.com
2. Click **"Download .deb"** (Ubuntu/Debian) or **".rpm"** (Fedora/Red Hat)
3. Open the downloaded file with your package manager
4. Or use terminal: `sudo apt install ./code*.deb` (Ubuntu)

**✅ You now have VS Code installed!**

## 🎨 Step 2: Install Elite Themes (3 Ways)

### Method A: Marketplace (Easiest) ⭐ RECOMMENDED

1. **Open VS Code**

2. **Open Extensions Panel:**
   - Click the 4-square icon on the left sidebar
   - OR press `Ctrl + Shift + X` (Windows/Linux)
   - OR press `Cmd + Shift + X` (Mac)

3. **Search for themes:**
   - Type **"Elite Themes 2026"** in the search box at the top
   - You'll see our extension with 100 themes

4. **Install:**
   - Click the green **"Install"** button
   - Wait 5 seconds while it installs
   - Done!

### Method B: Quick Command (Fast)

1. **Open Command Palette:**
   - Press `Ctrl + P` (Windows/Linux)
   - OR press `Cmd + P` (Mac)

2. **Type this command:**
   ```
   ext install elite-dev-studio.elite-themes-2026
   ```

3. **Press Enter**
   - Wait for installation
   - Done!

### Method C: Manual Install (Advanced)

1. Download the `.vsix` file from our [Releases page](https://github.com/YOUR_USERNAME/elite-themes-2026/releases)
2. In VS Code: `Ctrl + Shift + P` → type "Install from VSIX"
3. Select the downloaded `.vsix` file
4. Done!

**✅ Elite Themes are now installed!**

## 🖌️ Step 3: Activate a Theme

### Choose Your Theme:

1. **Open Theme Picker:**
   - Press `Ctrl + K`, **then** press `Ctrl + T` (Windows/Linux)
   - OR press `Cmd + K`, **then** press `Cmd + T` (Mac)
   - **Important:** Press `Ctrl + K` first, release, then press `Ctrl + T`

2. **Browse Themes:**
   - Use ↑↓ arrow keys to scroll through 100 themes
   - Each theme shows a live preview as you scroll
   - See how your code looks in real-time

3. **Select a Theme:**
   - Press `Enter` when you find one you like
   - Your entire editor changes instantly!

**✅ You're now using Elite Themes!**

## ⚙️ Step 5: Customize Settings (Optional)

### Make Themes Even Better:

1. **Open Settings:**
   - `File` → `Preferences` → `Settings` (Windows/Linux)
   - `Code` → `Preferences` → `Settings` (Mac)
   - OR press `Ctrl + ,` / `Cmd + ,`

2. **Adjust Font Size:**
   - Search: `font size`
   - Change `Editor: Font Size` to 14, 16, or 18
   - Bigger text = easier on eyes

3. **Change Font (Optional):**
   - Search: `font family`
   - Popular fonts:
     - `'Fira Code', monospace` (with cool arrows →)
     - `'JetBrains Mono', monospace`
     - `'Cascadia Code', monospace`

4. **Enable Ligatures (Makes Code Prettier):**
   - Search: `font ligatures`
   - Check ☑️ `Editor: Font Ligatures`
   - Now `=>` looks like a real arrow!

## 🆘 Troubleshooting

### Problem: "I can't find Elite Themes in Extensions"

**Solution:**
- Make sure you're connected to the internet
- Search for exact name: **"Elite Themes 2026"**
- Or search: **"elite-dev-studio"** (our publisher name)
- Still not there? Try Method B (Quick Command) from Step 2

---

### Problem: "Theme doesn't look like the screenshots"

**Solution:**
- Make sure you activated the theme (`Ctrl + K` → `Ctrl + T`)
- Check you selected the right theme name
- Restart VS Code (close and reopen)
- Some themes need syntax highlighting — open a code file (not blank editor)

---

### Problem: "Colors are too bright / too dark"

**Solution:**
- Try a different theme variant (we have 100 to choose from!)
- Or adjust brightness in Settings:
  - Search: `workbench color customizations`
  - Click "Edit in settings.json"
  - Advanced users can tweak colors here

---

### Problem: "I want my old theme back"

**Solution:**
- Press `Ctrl + K` → `Ctrl + T`
- Scroll to the top of the list
- Select "Dark+" (VS Code default) or your old theme
- Elite Themes doesn't delete your old themes!
