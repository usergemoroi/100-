### Features

✅ **100 Unique Themes** — Each targeting specific developer personas  
✅ **OKLCH Color Space** — Scientifically optimized for 12+ hour sessions  
✅ **7.5:1 Contrast** — WCAG AAA compliant for accessibility  
✅ **Semantic Highlighting** — Full support for modern token types  
✅ **AI Code Support** — Optimized for Copilot, Cursor, Claude  
✅ **Premium Variants** — Free version, premium upgrades available  
✅ **Low Blue Light** — Reduced eye strain for night coding  
✅ **Terminal Colors** — 16-color ANSI + bright variants  
✅ **Extension Support** — Works with Tailwind, Rust Analyzer, Pylance, etc.  
✅ **Multi-Language** — Optimized for 20+ programming languages
