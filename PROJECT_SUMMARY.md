## 🆘 Common Issues & Solutions

**"Can't publish to marketplace"**
- Check publisher name matches exactly
- Verify Personal Access Token has "Marketplace (Publish)" scope
- Run `npx vsce login YOUR_PUBLISHER` again

**"No one downloading"**
- Wait 24-48 hours for indexing
- Post on Reddit/Twitter
- Ask friends to try + review
- Add more screenshots

**"No sponsors yet"**
- Add more premium value (integrations, variants)
- Show social proof ("Join 50 sponsors")
- Post revenue milestones ("First $100!")
- Offer limited-time discount ("First 100 get 50% off")

**"Themes look wrong"**
- Test on multiple languages (JS, Python, Rust)
- Check terminal colors
- Verify contrast ratios
- Ask for feedback in Discord
