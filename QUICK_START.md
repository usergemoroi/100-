## 🚀 Install (Pick One Method)

### Method 1: VS Code Marketplace (Recommended)
```
1. Open VS Code
2. Press Ctrl+Shift+X (or Cmd+Shift+X on Mac)
3. Search "Elite Themes 2026"
4. Click Install
```

### Method 2: Command Line
```
1. Press Ctrl+P (or Cmd+P on Mac)
2. Paste: ext install elite-dev-studio.elite-themes-2026
3. Press Enter
```

### Method 3: Manual

## 💡 Pro Tips

### Change Theme Anytime:
`Ctrl+K → Ctrl+T` (same shortcut)

### Bigger Font:
Settings → search "font size" → change to 16 or 18

### Cool Font:
Settings → search "font family" → try `'Fira Code', monospace`

### Enable Ligatures:
Settings → search "font ligatures" → check the box

## 🆘 Issues?

**Theme doesn't show up?**

- Restart VS Code
- Search exact name: "Elite Themes 2026"

**Colors look wrong?**
- Make sure you activated the theme (Ctrl+K → Ctrl+T)
- Open a code file (not blank editor)
- Try a different theme
